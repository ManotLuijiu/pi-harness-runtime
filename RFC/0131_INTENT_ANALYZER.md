# RFC-0131 — Intent Analyzer

## Purpose

Analyze user intent from natural language.

## Motivation

Understand what users want:

- Command mapping
- Context-aware suggestions
- Disambiguation
- Fallback handling

See `IMPLEMENTATION/RFC-0131/FILES.md`.

## Acceptance Criteria

- [ ] Parse natural language intent
- [ ] Map to known commands
- [ ] Handle ambiguity
- [ ] Confidence scoring
