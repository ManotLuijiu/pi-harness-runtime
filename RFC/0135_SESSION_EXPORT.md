# RFC-0135 — Session Export

## Purpose

Export session data for analysis and replay.

## Motivation

Export capabilities:

- Session transcripts
- State snapshots
- Usage analytics
- Audit trails

See `IMPLEMENTATION/RFC-0135/FILES.md`.

## Acceptance Criteria

- [ ] Export session transcript
- [ ] Export session state
- [ ] JSON/Markdown formats
- [ ] Selective field export
